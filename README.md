# favze-crm
Favze Digital Marketing's Official Marketing and Customer Relationship Management Platform.

Every section of the CRM is its own page (`crm-dashboard.html`, `crm-deals.html`, `crm-settings.html`, and so on). All pages share `styles.css` and `app.js`. `index.html` opens the CRM at your default view.

Host the folder as-is on any static host (GitHub Pages works).
